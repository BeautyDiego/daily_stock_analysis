# A 股自动交易系统

私人部署的 A 股交易系统：每日自动选股、按评分卡复盘、程序化下单、盘中止损止盈，只在开盘与收盘各推一条简报。

实现细节见 [持仓跟踪与模拟盘设计](docs/cn-holding-tracker-design.md)，已知缺陷与改进计划见 [交易系统改进路线](docs/cn-trading-improvement-plan.md)。

## 一天的时间线

| 时间 | 动作 | 说明 |
|------|------|------|
| 08:45 | 采集宏观政策 | 政策新闻结构化为「行业 + 方向 + 强度」事件，落库可回溯 |
| 09:10 | 持仓复盘 | 5 维评分卡（趋势 30 / 相对强度 20 / 量能 15 / 风险 20 / 政策 15）→ `hold` / `reduce` / `exit` |
| 09:25 | 生成订单 | 买 = 上一个选股日的结果；卖 = 当日复盘建议。先卖后买，卖出资金当日可用于建仓 |
| 09:45 | 开盘成交 | 按实时价成交；高开超 3% 放弃、跌停跳过、现金不足自动降手数 |
| 10 / 11 / 13 / 14 点 | 盘中风控 | 实时价检查止损止盈，触发即清仓（遵守 T+1） |
| 15:10 | 同步日线 | 持仓 + 近期选股 + 双基准（510300 判市场环境、512100 算复盘超额） |
| 15:15 | 收盘结算 | 估值、当日与累计盈亏、收盘简报 |
| 16:20 | 每日选股 | 全市场筛选 → 因子打分 → 政策加成 → 去重与行业分散 → Top 5 |
| 16:40 | 次日验证 | 记录 T+1 涨跌与超额收益，供胜率统计 |

## 选股逻辑

四道筛子逐层收窄。

**1. 硬过滤**

价格 3–20 元、市值 ≥ 50 亿、日成交额 ≥ 1 亿、涨跌幅 -4% ~ +8.5%、`0 < PE ≤ 80`、`0 < PB ≤ 8`，剔除 ST 与退市风险标的。

**2. 因子打分**

权重经全市场分层回测校准（5532 只 × 120 个交易日，持有 5 日）：

| 因子 | 权重 | 回测结论 |
|------|------|----------|
| value（估值） | 0.30 | 方向未被否定，承接释放的权重 |
| stability（低波动） | 0.28 | 正向有效：IC +0.11，IC>0 比例 73% |
| size（规模） | 0.12 | 未验证 |
| theme_heat（题材） | 0.10 | 未验证 |
| momentum（动量） | 0.05 | 反向：IC -0.09，已从 0.20 降权 |
| liquidity（成交额） | 0.05 | 反向：IC -0.11，已从 0.18 降权 |
| activity（量比） | 0.05 | 反向：IC -0.05，已从 0.15 降权 |
| reversal（反转） | 0.05 | 无区分度 |

**3. 政策加成**

命中利好行业 +2 ~ +5 分，命中利空 -3 ~ -8 分，单票上限 ±10 分。

**4. 去重与分散**

5 个交易日内不重复推荐、同行业最多 2 只、已持仓不重复买入；强政策命中且分数上涨超 5 分可破例，每日最多 2 只。

## 风控参数

| 规则 | 参数 | 触发后 |
|------|------|--------|
| 硬止损 | 2×ATR20（限 5%~15%） | 盘中清仓 |
| 硬止盈 | 4×ATR20（限 10%~40%） | 盘中清仓 |
| 组合回撤 | -10%（近 60 个快照峰值起算） | 暂停开新仓，只允许卖出 |
| 单日亏损 | -3% | 当日不再开新仓 |
| 熊市降仓 | 510300 收盘跌破 MA20 | 仓位上限 5 → 2，单仓预算不变 |
| 滑点 | <5 元 0.4% / 5–15 元 0.25% / >15 元 0.15% | 计入成交价 |
| T+1 | 当日买入当日不可卖 | 含盘中风控 |

已用数据否决的规则（`--take-profit-study`，88,317 个买入点）：

- **分批止盈**：平均收益仅高 0.018pct，但多一笔卖出要多付约 0.13% 佣金，净效果为负
- **移动止盈**（+10% 激活、回落 5%）：比一次性硬止盈平均差 0.26pct。它只在「先涨到 +10%」的标的上启动，卖飞赢家又不保护输家

## 模拟盘

- 初始资金 2 万元；仓位数量按账户权益自动计算（目标单仓 4000 元，限 1–10 仓）
- 成本全计：佣金万 2.5（最低 5 元）、印花税千 1、按价格分档的滑点
- 账本幂等：`dedup_hash` 保证重复执行不重复记账，可安全补跑历史交易日
- 口径统一：已持仓标的按含佣金成本算浮盈，未持仓的关注标的按推荐价

## 常用命令

```bash
# 自动交易链路（cron 已配置，通常无需手动执行）
python main.py --paper-plan        # 09:25 生成订单
python main.py --paper-execute     # 09:45 按实时价成交
python main.py --paper-watch       # 盘中止损止盈检查
python main.py --paper-settle      # 15:15 收盘结算

# 选股与复盘
python main.py --screen-picks --picks-market cn
python main.py --review-holdings --no-notify
python main.py --sync-daily

# 手动干预
python main.py --paper-trade-now                                # 用最新信号立即建仓
python main.py --mark-position 600016:closed:3.90:0:2026-11-02  # 补记历史交割

# 参数验证（离线回测，不影响线上）
python main.py --factor-layering --layering-pool 0   # 因子分层回测（0 = 全市场）
python main.py --take-profit-study                   # 止盈方式对比
python main.py --portfolio-study                     # 行业上限 / 冷却期对比
```

## 部署

Docker 单容器 + 宿主机 cron。`src/`、`api/`、`main.py` 以挂载方式进容器，改后重启即可；前端产物在镜像的 `/app/static`，改前端需重新构建后拷入。

```bash
# 启动
docker compose -f docker/docker-compose.pickboard.yml up -d

# 更新后端（挂载目录，改完重启）
docker restart dsa-pickboard

# 更新前端
cd apps/dsa-web && npm ci && npm run build
scp -r static <host>:/opt/dsa-pickboard/
docker exec dsa-pickboard rm -rf /app/static
docker cp /opt/dsa-pickboard/static dsa-pickboard:/app/static
docker restart dsa-pickboard
```

cron 任务清单：

```
45 8  * * 1-5  --collect-macro
10 9  * * 1-5  --review-holdings
25 9  * * 1-5  --paper-plan
45 9  * * 1-5  --paper-execute
0 10,11,13,14 * * 1-5  --paper-watch
10 15 * * 1-5  --sync-daily
15 15 * * 1-5  --paper-settle
20 16 * * 1-5  --screen-picks --picks-market cn
40 16 * * 1-5  --verify-picks --picks-market cn
```

## 配置

关键环境变量（完整清单见 `.env.example`）：

| 变量 | 说明 |
|------|------|
| `TUSHARE_TOKEN` | 行业分类与全市场日线，配额受限时自动降级到新浪行业板块 |
| `WECHAT_WEBHOOK_URL` | 简报推送渠道（企业微信机器人） |
| `SCREENING_DATA_DIR` | 数据目录，行业映射文件 `industry_map.csv` 落在这里 |
| `INDUSTRY_MAP_FILES` | 行业映射文件路径，由 `--sync-daily` 自动生成 |
| `CN_COOLDOWN_TRADING_DAYS` | 跨日冷却交易日数，默认 5 |
| `CN_MAX_PER_INDUSTRY` | 同行业入选上限，默认 2 |
| `PAPER_INITIAL_CASH` | 模拟盘初始资金，默认 20000 |
| `PAPER_TARGET_SLOT_VALUE` | 目标单仓金额，默认 4000 |
| `PAPER_TRAILING_ENABLED` | 移动止盈开关，默认关闭 |
